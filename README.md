# shooting-cinema

Hemmabygge för skytteträning med laser: en projektor visar mål, en webbkamera ser var laserpricken träffar, och träffen blir ett musklick.

| Katalog | Innehåll |
|---------|----------|
| [`laser-mouse/`](laser-mouse/) | Electron-app: laserprick via webbkamera → musklick på vald skärm |
| [`games/`](games/) | Spel att skjuta på – vanliga webbsidor som reagerar på musklick |

## Plan
1. **Bron** – laser på vägg → musklick på skärm (`laser-mouse`)
2. **Spel** – mål att skjuta på, som reagerar på vanliga musklick
3. **Vapenattrapp** – laser som blinkar vid avtryck
