# Laser Mouse

The Electron app at the heart of Shooting Cinema: it watches a laser dot through a webcam and turns it into real mouse clicks on the screen of your choice.

```bash
npm install
npm start      # or: npm run dev (opens DevTools)
```

- **How to use it:** see the [main README](../README.md#quick-start).
- **How it works:** see [docs/TECHNICAL.md](../docs/TECHNICAL.md).
